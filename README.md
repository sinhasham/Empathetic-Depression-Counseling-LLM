# Empathetic Depression Counseling LLM

[![DOI](https://zenodo.org/badge/DOI/PLACEHOLDER.svg)](https://doi.org/PLACEHOLDER)

## Overview

This repository contains the implementation of an **LLM-based Empathetic Depression Counseling Framework** that combines:

- PHQ-9 Depression Severity Classification
- Chain of Thought (CoT)
- Chain of Empathy (CoE)
- Retrieval-Augmented Generation (RAG)
- Two-Layer Crisis Detection

The framework provides personalized mental health support while maintaining empathetic and safe conversational responses.

---

## Features

- PHQ-9 based depression assessment
- Severity prediction (Low / Medium / High)
- Chain of Thought reasoning
- Chain of Empathy prompting
- Retrieval-Augmented Generation
- Crisis detection and safety intervention
- Interactive Streamlit interface

## Installation

Clone the repository

```bash
git clone https://github.com/sinhasham/Empathetic-Depression-Counseling-LLM.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
